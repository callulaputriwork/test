🧸Software untuk MacBook M2 (Apple Silicon)

Semua tools di bawah gratis dan kompatibel dengan chip M2. Nggak perlu diinstall semua di hari pertama — ikuti aja urutan sesuai fase belajarnya.

1. Akun Google (Colab & Sheets) WAJIB

Nggak perlu install apa-apa! Google Colab dipakai buat latihan Python + Pandas langsung dari browser, gratis dan sudah ada semua library-nya.

  1. Buka colab.research.google.com pakai Safari/Chrome.
  2. Login pakai akun Google kamu.
  3. Klik "New Notebook" untuk mulai coding.

2. Visual Studio Code WAJIB

Text editor untuk nulis dan rapiin kode Python/SQL kamu di lokal, dipakai mulai Fase 3.

  1. Buka code.visualstudio.com/download.
  2. Pilih tombol "Apple Silicon" (khusus chip M1/M2/M3).
  3. Buka file .zip yang terunduh, drag ikon VS Code ke folder Applications.
  4. Buka VS Code dari Launchpad, install extension "Python" dan "Jupyter" dari tab Extensions (ikon 4 kotak di sidebar kiri).

3. DB Browser for SQLite WAJIB

Aplikasi ringan untuk praktik SQL secara lokal tanpa perlu setup server database.

  1. Buka sqlitebrowser.org/dl.
  2. Di bagian macOS, pilih file .dmg "Apple Silicon".
  3. Buka file .dmg, drag ikon aplikasi ke folder Applications.
  4. Buka aplikasinya — kalau muncul peringatan keamanan, buka System Settings → Privacy & Security → klik "Open Anyway".

4. Miniconda (Python lokal) OPSIONAL

Kalau nanti mau coding Python di laptop tanpa internet (nggak wajib karena Colab udah cukup untuk 32 hari pertama).

  1. Buka docs.conda.io/en/latest/miniconda.html.
  2. Unduh installer "Miniconda3 macOS Apple M1 64-bit pkg".
  3. Buka file .pkg, ikuti wizard instalasinya sampai selesai.
  4. Cek berhasil dengan buka Terminal, ketik conda --version.

5. Tableau Public WAJIB

Untuk bikin dashboard visualisasi data yang interaktif, dipakai di Fase 4.

  1. Buka public.tableau.com/s/download.
  2. Isi email, klik "Download the App".
  3. Buka file .dmg yang terunduh, drag ke folder Applications.
  4. Buka aplikasi, login/daftar akun Tableau Public (gratis).

6. Looker Studio (alternatif Tableau) OPSIONAL

Kalau mau versi berbasis web tanpa install, bisa pakai ini — cocok juga untuk bikin dashboard dari Google Sheets.

  1. Buka lookerstudio.google.com, login dengan akun Google.
  2. Klik "Blank Report" untuk mulai.

7. GitHub Desktop OPSIONAL

Untuk simpan dan pamerkan project portfolio kamu secara online — sangat membantu waktu melamar kerja nanti.

  1. Buat akun dulu di github.com.
  2. Unduh aplikasi di desktop.github.com.
  3. Buka file .zip, pindahkan ke folder Applications, lalu login pakai akun GitHub kamu.

🎀 Fase 1 — Fondasi: Excel/Sheets & Statistika Dasar

Hari 1–5 · 27–31 Agustus
⌄
  • Kenalan peran Data Analyst & tools yang dipakai sehari-hari WAJIB
  • Formula dasar Excel/Sheets: SUM, AVERAGE, COUNT, COUNTA, IF WAJIB
  • VLOOKUP / XLOOKUP & INDEX-MATCH WAJIB
  • Pivot Table & Conditional Formatting WAJIB
  • Statistika deskriptif: mean, median, modus, standar deviasi, distribusi data WAJIB
  • Shortcut & Data Validation di Excel/Sheets OPSIONAL
✏️ Contoh Soal
1. Diberikan kolom A (nama produk) dan kolom B (jumlah terjual) untuk 10 baris data. Buat formula total dan rata-rata penjualan. Jawaban: =SUM(B2:B11) untuk total, =AVERAGE(B2:B11) untuk rata-rata.
2. Kamu punya tabel harga di Sheet2 (kolom A = nama produk, kolom B = harga). Cari harga produk "Sabun Cair" dari Sheet1 pakai XLOOKUP. Jawaban: =XLOOKUP("Sabun Cair", Sheet2!A:A, Sheet2!B:B)
3. Hitung berapa banyak produk yang jumlah terjualnya lebih dari 50 unit (kolom B, baris 2–11). Jawaban: =COUNTIF(B2:B11, ">50")
4. Buat kolom status kelulusan: jika nilai di kolom C ≥ 75 tulis "Lulus", jika tidak tulis "Tidak Lulus". Jawaban: =IF(C2>=75, "Lulus", "Tidak Lulus")
5. Data penjualan harian selama sebulan punya standar deviasi yang besar dibanding rata-ratanya. Apa artinya bagi bisnis? Jawaban: artinya penjualan hariannya nggak stabil/fluktuatif tinggi, bukan tersebar merata di sekitar rata-rata — perlu diselidiki penyebabnya (musiman, promo, dsb).
📝 Latihan Soal
  • Buat Pivot Table untuk menghitung total penjualan per kategori produk dari data mentah 50 baris.
  • Gunakan Conditional Formatting untuk menyorot merah semua nilai penjualan di bawah rata-rata.
  • Hitung standar deviasi dan interpretasikan: apakah data penjualanmu tersebar merata atau bervariasi tinggi?
  • Gabungkan IF + AND untuk membuat kolom status "Target Tercapai" jika penjualan > 100 dan margin > 20%.
Sumber belajar: Exceljet.net · YouTube: Pivot Table Bahasa Indonesia · Khan Academy Statistics

💗 Fase 2 — SQL: Dari SELECT sampai JOIN

Hari 6–13 · 1–8 September
⌄
  • Konsep database, tabel, install & pakai DB Browser for SQLite WAJIB
  • SELECT, WHERE, operator logika (AND/OR/NOT) WAJIB
  • ORDER BY, LIMIT, DISTINCT WAJIB
  • Aggregate function: COUNT, SUM, AVG, MIN, MAX + GROUP BY WAJIB
  • HAVING & subquery dasar WAJIB
  • JOIN: INNER JOIN, LEFT JOIN WAJIB
  • Multiple JOIN & studi kasus gabungan WAJIB
  • Window function (RANK, ROW_NUMBER) & CTE (WITH) OPSIONAL
✏️ Contoh Soal
1. Dari tabel orders(order_id, customer_id, amount, order_date), tampilkan total amount per customer, urutkan dari terbesar. Jawaban: SELECT customer_id, SUM(amount) AS total FROM orders GROUP BY customer_id ORDER BY total DESC;
2. Gabungkan tabel orders dan customers(customer_id, name, city) untuk menampilkan nama pelanggan beserta total belanjanya. Jawaban: SELECT c.name, SUM(o.amount) AS total FROM customers c JOIN orders o ON c.customer_id = o.customer_id GROUP BY c.name;
3. Hitung berapa jumlah pelanggan unik (distinct) dari tiap kota di tabel customers(customer_id, name, city). Jawaban: SELECT city, COUNT(DISTINCT customer_id) AS jumlah_pelanggan FROM customers GROUP BY city;
4. Tampilkan semua order yang nilainya (amount) di atas rata-rata seluruh order. Jawaban: SELECT * FROM orders WHERE amount > (SELECT AVG(amount) FROM orders);
5. Cari pelanggan yang belum pernah melakukan order sama sekali. Jawaban: SELECT c.name FROM customers c LEFT JOIN orders o ON c.customer_id = o.customer_id WHERE o.order_id IS NULL;
📝 Latihan Soal
  • Tampilkan 5 pelanggan dengan transaksi terbesar sepanjang tahun 2024 (pakai WHERE tanggal + ORDER BY + LIMIT).
  • Cari pelanggan yang belum pernah bertransaksi sama sekali (gunakan LEFT JOIN + WHERE IS NULL).
  • Hitung rata-rata transaksi per kota dengan HAVING rata-rata di atas 500.000.
  • (Opsional) Buat ranking pelanggan teratas per kota menggunakan window function RANK().
Sumber belajar: SQLZoo · Mode SQL Tutorial · W3Schools SQL

  • Data cleaning: missing value, duplicate, ubah tipe data WAJIB
  • Data manipulation: filter, sort, groupby, merge WAJIB
  • List comprehension & OOP dasar di Python OPSIONAL
✏️ Contoh Soal
1. Kamu punya DataFrame df dengan kolom "harga". Tampilkan baris yang harganya di atas 50000. Jawaban: df[df['harga'] > 50000]
2. Hitung rata-rata "penjualan" per "kategori" pada DataFrame yang sama. Jawaban: df.groupby('kategori')['penjualan'].mean()
3. Kolom "umur" di DataFrame kamu punya beberapa nilai kosong (NaN). Isi nilai kosong itu dengan rata-rata umur. Jawaban: df['umur'] = df['umur'].fillna(df['umur'].mean())
4. Urutkan DataFrame berdasarkan kolom "penjualan" dari yang terbesar ke terkecil. Jawaban: df.sort_values('penjualan', ascending=False)
5. Kamu punya dua DataFrame, df_transaksi dan df_pelanggan, keduanya punya kolom "customer_id". Gabungkan keduanya jadi satu tabel. Jawaban: df_gabung = df_transaksi.merge(df_pelanggan, on='customer_id', how='left')
📝 Latihan Soal
  • Baca file CSV berisi data penjualan, cek jumlah missing value tiap kolom dengan df.isnull().sum().
  • Hapus baris duplikat dan ubah kolom "tanggal" menjadi tipe datetime.
  • Buat kolom baru "total" = harga × jumlah menggunakan operasi antar kolom.
  • Gabungkan (merge) dua DataFrame: data transaksi dan data pelanggan berdasarkan customer_id.
  • Cari 3 kategori produk dengan total penjualan tertinggi menggunakan groupby + sort_values.

🎀 Fase 4 — Visualisasi Data & Statistik Inferensial

Hari 23–27 · 18–22 September
⌄
  • Matplotlib dasar: line chart, bar chart WAJIB
  • Seaborn: histogram, boxplot, heatmap korelasi WAJIB
  • Statistik inferensial dasar: hypothesis testing, p-value, korelasi vs kausasi WAJIB
  • Bikin dashboard sederhana di Tableau Public / Looker Studio WAJIB
  • Interactive chart dengan Plotly OPSIONAL
✏️ Contoh Soal
1. Buat bar chart untuk menampilkan 5 kategori produk dengan penjualan tertinggi memakai Matplotlib. Jawaban: plt.bar(top5['kategori'], top5['penjualan']); plt.xticks(rotation=45); plt.show()
2. Kamu melihat boxplot penjualan dan ada titik-titik jauh di luar "kotak". Apa artinya? Jawaban: titik-titik itu adalah outlier — nilai yang jauh berbeda dari mayoritas data, perlu dicek apakah itu anomali atau data valid.
3. Histogram harga produk kamu miring ke kanan (ekor panjang di sisi kanan). Apa istilah statistiknya dan apa artinya? Jawaban: disebut right-skewed (skew positif) — artinya sebagian besar produk berharga rendah, tapi ada sedikit produk dengan harga sangat tinggi yang menarik "ekor" distribusi ke kanan.
4. Heatmap korelasi menunjukkan angka 0.85 antara "jam_iklan" dan "penjualan". Apa maknanya? Jawaban: ada korelasi positif yang kuat — makin banyak jam iklan, penjualan cenderung makin tinggi. Tapi ini belum tentu hubungan sebab-akibat (korelasi ≠ kausasi), perlu analisis lanjutan.
5. Hasil uji hipotesis menunjukkan p-value = 0.03 dengan ambang signifikansi 0.05. Apa kesimpulannya? Jawaban: karena p-value (0.03) lebih kecil dari 0.05, hasilnya signifikan secara statistik — cukup bukti untuk menolak hipotesis nol.
📝 Latihan Soal
  • Buat heatmap korelasi antar variabel numerik dalam dataset penjualan, interpretasikan korelasi terkuatnya.
  • Buat histogram distribusi harga produk, apakah polanya normal, skew kiri, atau skew kanan?
  • Import data ke Tableau Public, buat 1 dashboard berisi minimal 2 chart yang saling berkaitan.

✏️ Contoh Soal / Skenario
1. Kamu dapat dataset penjualan e-commerce. Pertanyaan bisnisnya: "Kategori produk apa yang paling menguntungkan tiap musim?" Bagaimana alur pengerjaannya? Jawaban: (1) Ambil dataset dari Kaggle → (2) Bersihkan data dengan Pandas → (3) Eksplorasi & agregasi per kategori/musim → (4) Visualisasikan dengan Seaborn/Tableau → (5) Tulis 3–5 insight kunci dalam bahasa awam.

Jawaban: hindari istilah teknis, fokus ke insight dan dampaknya — misalnya "kalau kita naikkan budget iklan, penjualan cenderung ikut naik", bukan "koefisien korelasinya 0.85".

Jawaban: telusuri dulu penyebab data hilang, lalu putuskan apakah diisi (imputasi), dihapus, atau dicari sumber data pengganti — jangan langsung dihapus tanpa dicek dampaknya ke hasil analisis.
